EE 202 Final Project

In this project, we built a cigar-box electric guitar and designed a notch (band-stop) filter to suppress the fundamental frequency of the G string (196 Hz) without affecting nearby notes. The circuit was built to achieve strong rejection at the target frequency, use a dual power supply, and preserve clean audio output for the rest of the instrument.

Process

Wood Design and Fabrication

We marked cuts on raw wood in class and then had the pieces manufactured. After the parts were returned, we prepared the cigar box body for the pickup, bridge placement, and final instrument assembly.

Filter Design and Test

The main goal of this design was to create a notch filter that blocks the fundamental frequency of an unfretted guitar string. The filter needed to reduce this frequency by at least 20 dB without attenuating adjacent notes, which required a high Q-factor. The circuit also needed a dual power supply (V+ and V-) to power the op-amps. To meet these requirements, we used a Twin-T notch filter design.

Printed-Circuit-Board (PCB) Layout

For the PCB layout, we designed it based on the provided reference layout.

Guitar and Electrical Component Assembly

We began by hand-soldering all PCB components, including the aviation plug, switch, and LED connections. Simultaneously, we fabricated the guitar by cutting the cigar box for the pickup, installing the bridges, and tuning the strings. Before putting everything together, we spent some time testing and debugging the PCB. Once an accurate output was confirmed, we completed assembly by soldering the final connections between the aviation plug, output jack, pickup, and the PCB.

Final Electrical Testing

We encountered significant issues during the final testing phase that required extensive debugging. Initially, the LED failed to light up, so we used a multimeter to troubleshoot voltages and connections. We discovered that the LED resistor was not connected to the V+ plane, so we soldered a jumper wire from the battery source to the resistor to fix it. Afterwards, we found that the first gain stage output was non-functional and noisy due to an imbalance between the voltage rails. The negative rail measured only -3.4V compared to +8.6V on the positive rail. Replacing the charge pump did not help, so we spent more time debugging the circuit by checking the output at each gain/filter stage. The problem was the feedback resistors and capacitors, so we resoldered all of them to ensure better connectivity. This resolved the power difference issue. Once the output signal was clean, we measured the notch filter frequency. It turned out to be about 191 Hz instead of the target 196 Hz. This slight deviation is likely caused by standard component tolerances in the capacitors or other poor connections.
